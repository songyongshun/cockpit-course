答：2. 触控交互系统的常见故障  
中控显示屏无法显示  
1）故障描述：启动车辆后，中控显示屏黑屏，无法正常显示。  
2）故障原因：  
①中控显示屏电源出现故障，如正极断路、负极断路或正负极同时断路。  
②中控显示屏内部损坏。  
③车机主机MP5内部损坏。

## 总结

触控交互系统的故障诊断与测试

- 控显示屏有12V和5V的电源，由MP5供电；MP5通过WIFI与计算平台通信。
- 控交互系统故障诊断流程：准备工作、故障确认、故障分析、故障检诊、故障消除确认；触控交互系统的系统测试流程：中控屏模式切换、网络环境配置、固件升级、系统复原、整理清洁。
- 控交互系统的常见故障现象为中控显示屏无法显示。
- 控交互系统的故障诊断包括12V电源检测、 5V电源检测。
